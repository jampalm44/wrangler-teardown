# Wrangler 2.5L Teardown

An interactive 3D model of a 2000 Jeep Wrangler (TJ) with the 2.5L four-cylinder engine and AX5 five-speed manual transmission. You can drag parts off the model, explode it apart, and click any part to learn what it does.

**Try it:** https://jampalm44.github.io/wrangler-teardown/

## What's in it

- The engine, broken down part by part, with a running animation of the pistons, cam, valves, and spark (firing order 1-3-4-2)
- The whole Jeep: frame, suspension, steering, brakes, drivetrain, fuel, exhaust, cooling, electrical, and air conditioning
- A gear selector that shows the overall gear ratio and speed for each gear in 2H, 4H, and 4L
- A rebuild challenge where you put the parts back where they belong

## Running it

It's a single HTML file. Open `index.html` in a web browser. It loads three.js from a CDN, so it needs an internet connection.

## A note on accuracy

The model is drawn from simple shapes, not from factory drawings. Sizes and positions are close, but not exact. Specs such as the axle ratio vary by Jeep, so check your own vehicle or a service manual before you buy parts or turn a wrench.
